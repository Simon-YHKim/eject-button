# Play Console — 개발자 개인정보(집주소·실명) 공개 제거 가이드

> 문제: Google Play 스토어의 앱 정보 하단에 **집주소·실명**이 공개돼 있음.
> 목표: **이메일 + 닉네임(브랜드명)만** 공개.
>
> ⚠️ 이 노출은 앱 코드/이 레포에서 새는 것이 **아니다**. 레포에는 집주소·실명이
> 하드코딩돼 있지 않다 (`EjectApplication.kt`에 PII 금지 주석까지 있음).
> 노출은 **Play Console 계정의 "거래자(Trader) 연락처" / "개발자 연락처"** 설정이
> 스토어 등록정보에 공개된 것이다. 따라서 해결도 **Play Console UI에서** 해야 한다.

---

## 왜 노출되는가 — EU DSA "거래자 상태"

2024년부터 Google Play는 EU 디지털서비스법(DSA)을 적용한다.

- 개발자가 **거래자(Trader)** 로 선언되면 → Google이 스토어 상세 페이지 하단에
  **실명(또는 법적 상호) + 물리적 주소 + 전화번호 + 이메일** 을 **공개(의무)** 한다.
  이건 개발자가 임의로 숨길 수 없다. (소비자 보호·투명성 목적)
- **비거래자(Non-trader)** 로 선언되면 → 이 이름/주소/전화번호는 **공개되지 않는다.**
  스토어에는 당신이 선택한 정보(예: 이메일)만 노출된다.

**우리 앱은 광고(AdMob) + 구독(`eject_premium_monthly`)으로 수익을 낸다.**
→ Google 기준 대부분 **거래자(Trader)** 에 해당한다. 그래서 실명·집주소가 공개된 것이다.

추가로, 개인(Personal) 계정으로 가입하면서 **집주소를 계정 주소로 등록**했기 때문에
그 집주소가 그대로 거래자 주소로 공개되고 있는 상황이다.

## 무엇이 가능하고, 무엇이 불가능한가 (솔직하게)

| 원하는 것 | 가능 여부 | 방법 |
|---|---|---|
| **이메일만 공개** | ✅ 가능 | 이미 공개 중. 유지. |
| **실명 대신 닉네임/브랜드명** | ⚠️ 부분 가능 | 스토어에 뜨는 **"개발자 이름(Developer name)"** 은 `Eject Button` 같은 브랜드명으로 변경 가능. 단, **거래자면 별도의 "거래자 법적 이름"** 은 공개 의무. |
| **집주소 완전히 숨기기** | ❌ 거래자면 불가 | 거래자는 주소 공개 의무. **집주소를 "집이 아닌 주소"로 교체**하는 것이 현실적 해법. |
| **전화번호 숨기기** | ⚠️ 조건부 | 스토어 등록정보의 전화번호는 선택 항목이라 제거 가능. 단, 거래자 연락처의 전화번호는 요구될 수 있음. |

> 요약: "이메일 + 닉네임만" 은 **비거래자일 때 100% 달성**된다. 거래자(광고·구독 수익)면
> 주소·법적 이름 공개는 피할 수 없고, 대신 **집이 아닌 주소로 바꿔 실제 거주지 노출을 막는 것**이
> 최선이다.

## 경로 A — 비거래자(Non-trader)로 선언 (가장 깔끔, 조건부)

**조건**: 앱으로 실질적 수익 활동을 하지 않는 경우에만 정직하게 선택 가능.
광고·구독으로 수익을 내고 있다면 이 경로는 **부적합**(허위 선언은 계정 정지 리스크).

1. Play Console → 좌측 하단 **Settings(설정)** → **Developer account(개발자 계정)**
   → **Account details(계정 세부정보)** (또는 앱별 **Store settings** 안의 DSA 섹션)
2. **Trader status(거래자 상태)** 항목을 찾는다.
3. **"I am not a trader / 저는 거래자가 아닙니다"** 선택 → 저장.
4. 저장 후 수 시간~1일 내 스토어에서 이름·주소·전화번호 공개가 사라지고
   이메일만 남는다.

## 경로 B — 거래자(Trader)지만 집주소 노출만 막기 (수익 앱의 현실적 해법)

광고·구독 수익이 있으면 이 경로가 정답이다. 이름/주소 공개는 유지하되
**"집" 대신 다른 주소**를 쓴다.

### B-1. 집이 아닌 주소 확보 (아래 중 택1)
- **가상 오피스 / 비상주 사무실 주소** (월 몇 만원, 우편 수령 가능) — 가장 흔한 해법
- **사서함(우체국 사서함)** — 우편 수령 가능한 실제 주소여야 함
- **사업자 등록 후 사업장 주소** — 개인사업자 내면 사업장 주소 사용 가능

> Google은 "우편을 실제로 받을 수 있는 유효한 주소"를 요구한다. 가짜 주소·존재하지
> 않는 주소는 검증 실패/정지 사유. 위 방법은 모두 유효한 실주소다.

### B-2. Play Console에서 주소 교체
1. Play Console → **Settings → Developer account → Account details**
2. **Address(주소)** / **Contact address** 를 B-1에서 확보한 주소로 변경 → 저장.
3. 결제 프로필 주소도 별도로 있으면 함께 변경:
   **Settings → Payments profile(결제 프로필) → 사업자/개인 주소** 수정.
4. 거래자 연락처(DSA) 주소도 위 계정 주소를 따라가는지 확인.
   앱별 **Store settings → Trader/DSA** 섹션에서 표시 주소 재확인.

### B-3. 공개 "개발자 이름"을 브랜드명으로
1. **Settings → Developer account → Account details → Developer name(개발자 이름)**
2. `Eject Button` 처럼 브랜드/닉네임으로 변경 → 저장.
   (스토어 상단 "개발자: OOO" 가 이걸로 바뀐다. 단, 하단 DSA 거래자 블록의
   법적 이름은 별개로 공개될 수 있음.)

## 경로 C — 스토어 등록정보의 연락처 정리 (A/B 공통, 지금 바로)

이건 거래자 여부와 무관하게 즉시 정리 가능하다.

1. Play Console → **Grow → Store presence → Main store listing**
   → 맨 아래 **Contact details(연락처 세부정보)**
2. **Phone(전화번호)**: 개인 번호가 들어 있으면 **삭제** (선택 항목).
3. **Email**: `simonkim250405@gmail.com` 유지 (공개 OK).
4. **Website**: `https://eject-button.hwanydanh.workers.dev/` 유지.
5. **Save**.

## 권장 결정 트리

```
광고·구독으로 수익을 내는가?
├─ 아니오 (순수 취미/무수익) ──▶ 경로 A (비거래자 선언) → 이름·주소·전화 전부 비공개
└─ 예 (AdMob/구독 있음) ───────▶ 경로 B (집주소 → 가상오피스/사서함 교체)
                                   + 경로 C (스토어 전화번호 제거)
```

우리 앱은 광고 + 구독이 붙어 있으므로 **경로 B + C 조합**이 현실적 정답이다.
